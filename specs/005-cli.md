# 005 — CLI (`cmd/eanbot`)

`main.go`: `os.Exit(run(os.Args[1:], os.Stdout, os.Stderr))`. Toda la lógica
en `run(args []string, stdout, stderr io.Writer) int` (testeable sin
procesos). `flag.FlagSet` por subcomando con `ContinueOnError` y salida a
`stderr`.

## Uso

```
eanbot crawl <url> [-db eanbot.db] [-max-pages 500] [-max-depth 10]
                   [-concurrency 4] [-delay 500ms] [-timeout 15s]
                   [-user-agent UA] [-include-subdomains] [-ignore-robots]
                   [-no-sitemaps] [-json] [-quiet]
eanbot serve       [-db eanbot.db] [-addr :8345]
eanbot crawls      [-db eanbot.db] [-json]
eanbot pages <crawl-id> [-db eanbot.db] [-status 2xx|3xx|4xx|5xx|error|blocked] [-q texto] [-json]
eanbot broken <crawl-id> [-db eanbot.db] [-json]
eanbot version
eanbot help | -h | --help
```

Sin subcomando o desconocido → uso en `stderr`, código 2. Error de flags →
código 2. Error de ejecución → mensaje `error: ...` en `stderr`, código 1.
Éxito → 0.

## `crawl`

1. Abre el store (`-db`), construye `crawler.Config` desde flags, valida
   (errores → todos en stderr, código 2).
2. `store.CreateCrawl`; ejecuta `crawler.Run` con `HTTPFetcher` real y un
   Sink que guarda cada página y, salvo `-quiet`, escribe una línea de
   progreso en `stderr`: `[  12] 200  text/html   https://...` (índice
   incremental, código o `BLOQ`/`ERR`, tipo, URL).
3. `Ctrl-C` (SIGINT) cancela el contexto: el rastreo termina como
   `cancelled`, se imprime el resumen igualmente y el código es 130.
4. Al terminar: `FinishCrawl` y resumen en `stdout`:

```
Rastreo #3 · https://xavibolivar.xavi.net · done
Páginas: 57   2xx: 52   3xx: 3   4xx: 2   5xx: 0   Errores: 0   Bloqueadas: 1
Noindex: 0    Profundidad máx.: 4   Media: 231 ms   En cola sin visitar: 0
Enlaces rotos: 2 (ver: eanbot broken 3)
```
Con `-json`: `{"crawl":crawl,"summary":summary,"stats":{"fetched":..,"blocked":..,"errors":..,"queued":..,"sitemaps":..}}`.

## `serve`

Imprime en stdout `eanbot escuchando en http://<addr>` (si addr empieza por
`:`, mostrar `localhost:<puerto>`), crea `server.New` y llama a una función
`listenAndServe(ctx context.Context, addr string, h http.Handler) error`
inyectable (variable de paquete) para poder testear sin abrir sockets.
SIGINT/SIGTERM → `Shutdown` con 10 s de gracia.

**Desviación respecto a una versión anterior de esta spec**: la firma de
`listenAndServe` lleva un `context.Context` como primer parámetro (en lugar
de `(addr string, h http.Handler) error`), porque la implementación por
defecto necesita saber cuándo se cancela el contexto (SIGINT/SIGTERM) para
arrancar el `http.Server` real, esperar su cierre y llamar a
`srv.Shutdown(shutdownCtx)` con 10 s de gracia — sin `ctx` no hay forma de
que la función inyectable observe la cancelación por sí misma. Los tests
sustituyen la variable por una función falsa que no abre sockets.

## `crawls`, `pages`, `broken`

Tablas de texto alineadas (`text/tabwriter`) o JSON con `-json`
(`{"crawls":[...]}`, `{"pages":[...],"total":N}`, `{"broken":[...]}`).
`crawl-id` no numérico o inexistente → `error: rastreo no encontrado`, 1.
